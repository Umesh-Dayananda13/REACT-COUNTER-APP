This commit introduces a fully functional and responsive React Counter App. 

✅ Features:
- Increase, Decrease, and Reset functionality using useState.
- Styled with CSS (gradient background, hover effects, and button animations).
- Mobile-responsive with a clean UI.
- Uses .gitignore to exclude node_modules.

💡 How to Run:
1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Start the app using `npm start`.

Enjoy the interactive counter app! 🚀
